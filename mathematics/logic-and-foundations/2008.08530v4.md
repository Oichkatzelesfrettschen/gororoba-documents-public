Introduction

The purpose of these notes is to give a categorical semantics for the transpension type [ND24], which is
right adjoint to a potentially substructural dependent function type.
• In section 2 we discuss some prerequisites.
• In section 3, we define multipliers and discuss their properties.
• In section 4, we study how multipliers lift from base categories to presheaf categories.
• In section 5, we explain how typical presheaf modalities can be used in the presence of the transpension type.
• In section 6, we study commutation properties of prior modalities, substitution modalities and multiplier modalities.

2.3.2

On the Yoneda-embedding

We consider the Yoneda-embedding y : W → Ŵ.
Proposition 2.3.1. A morphism φ : V → W in W is:
• Mono if and only if yφ is mono,
• Split epi if and only if yφ is epi.
Proof. It is well-known that a presheaf morphism σ : Γ → ∆ is mono/epi if and only if σ ◦ ⌞⌟ : (W ⇒
Γ) → (W ⇒ ∆) is injective/surjective for all W . Now yφ ◦ ⌞⌟ = φ ◦ ⌞⌟. So yφ is mono if and only if
φ ◦ ⌞⌟ is injective, which means φ is mono. On the other hand, yφ is epi if and only if φ ◦ ⌞⌟ is surjective,
which is the case precisely when id is in its image, and that exactly means that φ is split epi.

Multipliers in the base category

3.1

Definition

Definition 3.1.1. Let W be a category with terminal object ⊤. An object W is pointable§A if () : W → ⊤
is split epi. A category is objectwise pointable§A if every object is pointable.
We have carefully chosen the above terminology to emphasize (1) that pointability is a property, not
structure (the corresponding structure is called pointed), and (2) that objectwise pointability does not
require that the pointings can be chosen naturally.
Definition 3.1.2. Let W be a category with terminal object ⊤. A multiplier for an object U ∈ V is a
functor ⌞⌟ ⋉ U : W → V such that ⊤ ⋉ U ∼
= U .9 This gives us a second projection π2 : ∀W.W ⋉ U → U .
We define the fresh weakening functor as ℲU : W → V/U : W ↦→ (W ⋉ U, π2 ), which is essentially
the action of the multiplier on slice objects over ⊤.
We say that a multiplier is:
• Endo if it is an endofunctor (i.e. V = W), and in that case:
– Copointed§A if there is also a first projection π1 : ∀W.W ⋉ U → W ,
– A comonad§A if there is additionally a ‘diagonal’ natural transformation ⌞⌟⋉δ : ∀W.W ⋉U →
(W ⋉ U ) ⋉ U such that π1 ◦ (W ⋉ δ) = (π1 ⋉ U ) ◦ (W ⋉ δ) = id.
– Cartesian if it satisfies the universal property of the cartesian product with U ,
• ⊤-slice faithful§A if ℲU is faithful, or equivalently (lemma 3.2.2) if ⌞⌟ ⋉ U is faithful,
• ⊤-slice full§A if ℲU is full,
• ⊤-slice objectwise pointable§A if π2 : W ⋉ U → U is always split epi, and in that case:
– ⊤-slice shard-free§A if ℲU is essentially surjective on objects (V, ψ) such that ψ is split epi,
i.e. if every such object in V/U is isomorphic to some ℲU W .
– A split epi slice object (V, ψ) that is not in the image of ℲU even up to isomorphism, will be
called a shard of the multiplier.
• ⊤-slice right adjoint§A if ℲU has a left adjoint ∃U : V/U → W.10 We denote the unit as copyU :
Id → ℲU ∃U and the co-unit as dropU : ∃U ℲU → Id.

Dealing with unpointability

Since multipliers that are not ⊤-slice objectwise pointable, do not guarantee that ℲU produces split epi

Definition 3.4.6. Given a multiplier ⌞⌟ ⋉ U : W → V, we say that a morphism φ : V → U is dimensionally split if there is some W ∈ W such that π2 : W ⋉ U → U factors over φ. The other factor χ

of V/U of dimensionally split slice objects.
The ⊤-slice objectwise pointability condition for multipliers is automatically satisfied if we replace
‘split epi’ with ‘dimensionally split’:
Corollary 3.4.7. For any multiplier ⌞⌟ ⋉ U , any projection π2 : W ⋉ U → U is dimensionally split.
Proposition 3.4.8. Take a multiplier ⌞⌟ ⋉ U : W → V.
1. If φ ◦ χ is dimensionally split, then so is φ.
2. The identity morphism idU : U → U is dimensionally split.
3. If φ : V → U is dimensionally split and χ : V ′ → V is split epi, then φ ◦ χ : V ′ → U is
dimensionally split.
4. Every split epimorphism to U is dimensionally split.
5. If ⌞⌟ ⋉ U is ⊤-slice objectwise pointable, then every dimensionally split morphism is split epi.
Proof.

1. If π2 : W ⋉ U → U factors over φ ◦ χ, then it certainly factors over φ.

2. Since π2 : ⊤ ⋉ U → U factors over idU .
3. Let φ′ be a dimensional section of φ and χ′ a section of χ. Then χ′ ◦ φ′ is a dimensional section of
φ ◦ χ.
4. From the previous two points, or (essentially by composition of the above reasoning) because if
χ : U → V is a section of φ : V → U , then χ ◦ π2 : ⊤ ⋉ U → V is a dimensional section of φ.
5. If φ : V → U is dimensionally split, then some π2 : W ⋉ U → U factors over φ. Since π2 is split
epi, idU factors over π2 and hence over φ, i.e. φ is split epi.

Changelog

The first version of this technical report and the associated paper appeared in 2020. Since then, there have
been significant changes, primarily terminological ones. To help out readers coming back to these texts
after having consulted earlier versions (or associated presentations), we list the most important changes
here.

A.1

Definition 3.1.1

• Unpointable objects were formerly called spooky,
• Not objectwise pointable categories were formerly called spooky.

A.2

Definition 3.1.2

• Copointed multipliers were formerly called semicartesian,
• Multipliers that are comonads were formerly called 3/4-cartesian,
• ⊤-slice faithful multipliers were formerly called cancellative,
• ⊤-slice full multipliers were formerly called affine,
• Not ⊤-slice objectwise pointable multipliers were formerly called spooky,
• ⊤-slice shard-free multipliers were formerly called connection-free, and shards were formerly
called connections,
• ⊤-slice right adjoint multipliers were formerly called quantifiable.

A.3

Definition 3.4.1

• A morphism of copointed multipliers was formerly called a semicartesian morphism of multipliers,
• A comonad morphism of multipliers was formerly called a 3/4-cartesian morphism of multipliers.

A.4

Quotient theorem

The quotient theorem was formerly called kernel theorem.

A.5

Definition 3.5.1

Slicewise faithful / full / shard-free / right adjoint multipliers were formerly called strongly cancellative
/ affine / connection-free / quantifiable.
A previous version of paper and technical report featured only the now obsoleted definition of indirect
shards/connections and slicewise indirect shard-freedom / strong indirect connection-freedom, that was
based on the indirect boundary and indirectly dimensionally split morphisms. These notions are obsolete
and are retained solely for consistency with [Nuy20, ch. 7]. The qualifier ‘indirect’ was only added a
posteriori to distinguish with the more appropriate direct notions.

A.6

Definition 4.1.1

Presheafwise faithful / full / shard-free / right adjoint multipliers were formerly called providently
cancellative / affine / connection-free / quantifiable.
⊤-slice elementally faithful / full multipliers were formerly called elementally cancellative / affine.
A similar note as above applies to (in)direct shards/connections, shard/connection-freedom, boundaries and dimensional splitness.
